# Quality Score

Citizen App 的品質不以「用了多少 Framework」評分。

建議 Review 面向：

| 面向 | 問題 |
|---|---|
| Business Clarity | SPEC 是否清楚？ |
| Correctness | Business Rule 是否有測試？ |
| Simplicity | 是否能用更少技術完成？ |
| Security Boundary | 是否繞過 Enterprise API / SSO？ |
| Maintainability | Feature 是否集中、容易找到？ |
| Verification | Agent 是否提供可重複的證據？ |
| Graduation Risk | 是否已經超過 Citizen App 的合理範圍？ |
