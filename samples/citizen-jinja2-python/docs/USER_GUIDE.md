# 使用者操作說明

## Master / Detail

1. 開啟 `/master-detail`。
2. 右上選擇 Product。
3. 上方 Form 顯示 Product Master。
4. 下方 Grid 顯示 Trading Detail。
5. 可編輯 Product；可新增、修改、刪除 Trading。

## Dashboard

1. 開啟 `/dashboard`。
2. 查看 KPI 與 Product Trading Amount。
3. 點擊任一 Product Bar。
4. 下方月別圖表與 Trading Grid 會 Drill-down 至該 Product。
