# Citizen Template 技術棧

本專案是 **Citizen Developer Python 版**，不是 React 專案。

## Runtime

- Python
- FastAPI
- Pydantic
- Jinja2
- SQLite

## Frontend

- Server-side Rendering
- Bootstrap 5
- ECharts
- Vanilla JavaScript

## 明確不使用

- React
- Vue
- Vite
- npm / Node.js build chain
- Redux / Zustand

若需求需要大量 Client State、跨 Component 狀態或複雜 SPA 互動，應停止擴充本模板並升級由 Solution Builder / IT 評估。
