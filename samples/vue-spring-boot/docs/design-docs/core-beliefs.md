# Core Beliefs

1. AI 可以大量寫程式，但不能取代 Problem Definition。
2. Human Review 應聚焦 Business Rule、Contract、Architecture 與 Evidence，不應只靠逐行閱讀大量 AI code。
3. 能被 Compiler、Test、Lint、Architecture Rule 驗證的規則，就不要只靠文件提醒。
4. Business Feature 應集中放置，降低人與 Agent 找 Context 的成本。
5. Framework 越少越好，直到問題真的需要更高層 abstraction。
6. 企業系統的長期價值來自穩定邊界與可驗證變更，不來自使用最多新技術。
7. Database Schema 是受治理的企業資產，不由 Application 自動修改。
