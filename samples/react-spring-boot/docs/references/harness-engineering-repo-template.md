# Harness Engineering Repo Template Reference

本 Repository 的文件路由與 Agent Harness 設計參考：

Walking Labs — Learn Harness Engineering  
OpenAI Advanced Repo Template

https://github.com/walkinglabs/learn-harness-engineering/tree/main/docs/zh-TW/resources/openai-advanced/repo-template

採用的核心概念：

- Root `AGENTS.md` 保持精簡，作為文件路由。
- `ARCHITECTURE.md` 提供頂層系統地圖。
- Product Spec 與 Execution Plan 版本化並與程式共置。
- Quality / Reliability / Security 成為 Repository Knowledge。
- Agent 完成工作需要可執行證據。
- 重複 Review 問題應逐步機械化。

本專案不是原 Template 的逐字複製，而是依公司 Spring Boot / React / SQLite Local Standalone 情境重構。
