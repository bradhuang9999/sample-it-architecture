92. Decorator

Python @... 是 decorator syntax。

專案會看到：

@router.get(...)
@router.post(...)
@app.get(...)
@app.exception_handler(...)
@contextmanager
@asynccontextmanager
@pytest.fixture
@staticmethod
@dataclass(...)

Decorator 的概念是：

用另一個 callable 包裝 / 登記原 function 或 class，加入額外行為或 metadata。

不要因為 Java annotation 也用 @ 就認為兩者底層機制相同。

94. List Comprehension

return [_product(row) for row in rows]

等價概念：

result = []
for row in rows:
    result.append(_product(row))

適合簡單 mapping，不要把複雜多層 business logic 全塞 comprehension。

95. Context Manager：with

DB connection / file 等 resource 很適合。

96. Generator / yield

DB helper 可以：

@contextmanager
def connection() -> Iterator[sqlite3.Connection]:
    conn = sqlite3.connect(...)
    try:
        yield conn
        conn.commit()
    except Exception:
        conn.rollback()
        raise
    finally:
        conn.close()

yield 暫停 function，把 resource 交給 with block；退出後繼續 cleanup code。

97. try / except / finally / raise

try:
    yield conn
    conn.commit()
except Exception:
    conn.rollback()
    raise
finally:
    conn.close()

Bare raise：重新拋出目前正在處理的 exception。

119. Vanilla JS fetch() Wrapper

async function api(url, options = {}) {
  const response = await fetch(url, options)
  const body = await response.json().catch(() => null)

  if (!response.ok) {
    throw new Error(body?.message ?? 'Request failed')
  }

  return body
}

專案需要理解：

  • default parameter options = {}。
  • fetch()。
  • response.ok。
  • .json() 回 Promise。
  • .catch(...)。
  • optional chaining / nullish coalescing。
  • throw new Error()。

124. Python sqlite3

Connection：

conn = sqlite3.connect(database_path)
conn.row_factory = sqlite3.Row

Foreign key：

conn.execute("PRAGMA foreign_keys = ON")

Query：

rows = conn.execute(
    """
    SELECT PROD_ID, PROD_CODE, PROD_NAME
    FROM SAMPLE_PROD
    ORDER BY PROD_CODE
    """
).fetchall()

Parameterized SQL：

row = conn.execute(
    "SELECT * FROM SAMPLE_PROD WHERE PROD_ID = ?",
    (prod_id,),
).fetchone()

注意 (prod_id,) 的逗號：Python 單一元素 tuple。

Update：

cursor = conn.execute(sql, params)
if cursor.rowcount == 0:
    raise ConflictError(...)

Auto ID：

trading_id = cursor.lastrowid

Initialize script：

conn.executescript(schema_sql)

Transaction：

conn.commit()
conn.rollback()
